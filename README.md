## 善悪と損得

善悪と損得は、多くの場面で重なります。嘘をつかない、約束を守る、相手を騙さないといった行いは、長い目で見れば信用として返ってきます。近江商人の「三方よし」や渋沢栄一の『論語と算盤』が説いたのも、この一致です。関係が続く世界では、善悪は「長期的な損得」をまとめたルールとして働いています。

ただ、本当に試されるのは両者がずれたときです。誰にも見られず、バレる心配もなく、ズルをすれば得をする場面がそうです。プラトンは『国家』で、姿を消せる「ギュゲスの指輪」を持っても人は正しくいられるかと問いました。カントも、客を騙さない商人が「損だから」そうしているなら、行いは正しくても道徳的な価値はないと区別しています。損得だけで善悪を説明しようとすると、いちばん肝心な場面で説明がつかなくなります。

逆に、損得を無視した善悪も危ういものです。二宮尊徳の言葉とされる「道徳なき経済は罪悪であり、経済なき道徳は寝言である」のとおり、暮らしを支えられない善意は空回りしがちです。

両者を対立させて考えるより、「一致するときは迷わず進み、ずれたときにどちらを取るか」に人となりが出る、という見方もできます。
